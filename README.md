# note-trainer
🎵 Тренажёр нот
Небольшое веб-приложение для изучения нот на нотном стане.

На экране — нотный стан со скрипичным и басовым ключами. Появляется нота, нужно нажать кнопку с её правильным названием (До/Ре/Ми… или C/D/E…).

Возможности
Четыре режима: только скрипичный ключ, только басовый, оба по очереди (нота на одном из станов) и оба сразу (одна и та же нота, например До, показывается одновременно на скрипичном и басовом стане)
Названия нот: слоговые (До Ре Ми), буквенные (C D E) или оба
Добавочные линейки (ноты выше/ниже стана), можно отключить
Звук ноты при ответе
Счёт, серия правильных ответов, рекорд (сохраняется в браузере)
Управление с клавиатуры: 1–7 или C D E F G A B
Запуск
Откройте index.html в любом браузере — сборка и сервер не нужны.

Стек
Один HTML-файл: SVG для стана, ванильный JavaScript, Web Audio API для звука, шрифт Bravura для ключей.
