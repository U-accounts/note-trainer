# note-trainer
🎵 Тренажёр нот
Небольшое веб-приложение для изучения нот: на нотном стане появляется нота, её нужно найти на фортепианной клавиатуре.

Возможности
Нотный стан со скрипичным и басовым ключами, с добавочными линейками
Четыре режима: только скрипичный ключ, только басовый, оба по очереди и «оба сразу» — одна и та же нота (например, До) показывается одновременно на обоих станах, и нажать нужно обе клавиши
Два способа ответа (переключатель «Отвечать»):
клавишами — фортепианная клавиатура на четыре октавы: большая, малая, первая и вторая (октавы подписаны). Отвечать нужно с учётом октавы. На телефоне клавиатура остаётся одной горизонтальной лентой с крупными клавишами: её листают пальцем, а полоска-миникарта сверху показывает, какая часть сейчас видна, и позволяет быстро перейти к нужной октаве. Если повернуть телефон набок, все четыре октавы помещаются целиком и прокрутка не нужна
кнопками с названиями — семь кнопок До…Си, октава не важна; работают и клавиши 1–7 / C D E F G A B
Диезы и бемоли — отдельный режим (галочка «диезы и бемоли»): перед нотой появляется знак. В режиме клавиш отвечают чёрной клавишей, в режиме кнопок сначала выбирают знак (♭ ♮ ♯), затем название
Звук ноты, счёт, серия правильных ответов и рекорд (сохраняется в браузере)
Выбор названий для подсказок: слоговые (До Ре Ми), буквенные (C D E) или оба
Запуск
Откройте index.html в любом браузере — сборка и сервер не нужны.

Стек
Один HTML-файл: SVG для стана и клавиатуры, ванильный JavaScript, Web Audio API для звука, шрифт Bravura для ключей.
